# 🎶 Love lyrics site

A cute website built with love 💖  
Sweet, simple, and made to bring a smile to someone special ✨ 

---

## 🛠 Tech Stack

- ⚛️ **Next.js** – React Framework for building fast UI
- 🎨 **Tailwind CSS** – For modern and responsive styling
- 🎞️ **Motion** – Smooth entrance and fade animations

---

## 🖥 Local Setup

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Anuj579/love-lyrics-site.git

# Navigate into the folder
cd love-lyrics-site

# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser to explore the site.
